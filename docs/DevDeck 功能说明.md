# DevDeck 功能说明

更新于 2026-11-17

## 产品简介

DevDeck（开发台）是一款运行在本机的桌面工具箱，帮助个人开发者看清自己使用 Claude Code 的用量、费用和历史会话。它支持 Windows 和 macOS，常驻系统托盘，无需账号，也不联网上传任何数据。

- **适合谁**：日常使用 Claude Code 的个人开发者。
- **解决什么**：用量和费用一目了然，套餐额度剩多少、何时重置随时可查，历史会话可以回看。
- **怎么做到**：只读取本机 Claude Code 自己写下的日志，在本地统计和展示。

## 功能一览

DevDeck 目前提供五项功能：每日用量、套餐额度、会话浏览、Insights 报告和托盘常驻。

### 每日用量

按天统计 Claude Code 的 token 用量和估算费用。

- **指标卡**：今日 tokens、今日费用、近 7 天、近 30 天，并与上一周期对比。
- **筛选**：今天 / 7 天 / 30 天 / 本月 / 自定义日期；按项目、按模型多选；最近活跃的项目置顶。
- **趋势图**：每日 token 堆叠柱，可按 token 类型（input / output / cache 写 / cache 读）或按模型切换；下方对齐显示每日费用。
- **明细表**：每天一行，展开可看各模型拆分。
- **CSV 导出**：按当前筛选导出「每日 × 模型」明细，可直接用 Excel 打开。
- **费用估算**：按内置的官方价格表计算，区分 5 分钟 / 1 小时缓存写入；价格可按模型自定义。

### 套餐额度

在每日用量页顶部显示套餐的已用百分比和重置时间，包括当前会话、本周和各模型的额度。读数来自本机 Claude Code 的 `/usage` 命令，不调用模型、不产生费用，可在设置中关闭。

### 会话浏览

回看 Claude Code 的历史会话。

- **会话列表**：按关键字、项目、日期筛选，显示标题和首条提示。
- **会话详情**：按 Claude Code 实际的对话主线展示，助手回复按 Markdown 渲染并高亮代码；思考过程、工具调用和系统内容默认折叠。
- **子代理与压缩点**：可进入子代理的对话，压缩前的历史也能接着看。
- **「仅显示用户请求」**：只看自己提过的问题，快速回顾一个会话做了什么。
- **快捷操作**：复制 `claude --resume <会话ID>` 命令继续该会话；在文件管理器中打开项目目录。

### Insights 报告

归档并查看 Claude Code 原生 `/insights` 命令生成的使用分析报告。

- **自动归档**：发现新报告就保存一份，去重存放；即使 Claude Code 覆盖或清理了原文件也能继续查看。
- **一键生成**：在后台调用本机 Claude Code 生成新报告，并显示本次估算费用。
- **中文翻译**：原生报告只有英文，DevDeck 可将其翻译为中文，并可在中文和原文之间切换。
- **管理**：用浏览器打开、删除单份、清除全部归档。

### 托盘常驻

- 关闭窗口默认最小化到托盘（也可设为直接退出）。
- 鼠标悬停托盘图标即可看到今日用量、费用和套餐额度。
- 托盘菜单支持立即刷新、开关开机自启、退出；开机自启时只驻留托盘，不弹出窗口。
- 自动刷新间隔可选 1 / 5 / 15 / 30 分钟或关闭。

## 隐私与数据

DevDeck 自身不联网、不需要账号，所有统计都在本机完成。只有你主动使用的两项功能会通过本机 Claude Code 连接 Anthropic，见下表。

- **只读不写**：只读取 Claude Code 的日志，不修改、不删除。
- **会话正文不入库**：本地数据库只保存用量数字和会话索引（标题、时间、项目）；查看会话时直接读取日志，不缓存。
- **数据位置**：Windows 为 `%APPDATA%\com.byzer.devdeck\`，macOS 为 `~/Library/Application Support/com.byzer.devdeck/`，包含配置 `config.json`、数据库 `devdeck.db` 和 Insights 归档 `insights/`。删除该目录即清除全部数据。

| 功能 | 是否联网 | 发送什么 | 费用 |
| --- | --- | --- | --- |
| 每日用量、会话浏览、归档查看 Insights | 否 | 不发送 | 无 |
| 套餐额度 | 是，由 Claude Code 查询 | 仅查询账号额度 | 无 |
| Insights 生成新报告 | 是，由 Claude Code 完成 | 最近会话内容，供模型分析 | 按量计费，单次约 $1–2 |
| Insights 翻译为中文 | 是，由 Claude Code 完成 | 报告中的文字 | 单次约 $0.2 |

生成和翻译都需要手动点击，执行前会弹窗说明费用和发送内容；不需要的话可在设置中关闭套餐额度和翻译。费用为本机实测值，随会话数量变化。

## 系统要求与安装

Windows 提供安装包和免安装的便携版，macOS 提供同时支持 Apple 芯片和 Intel 的通用包，均从 [DevDeck 发布页面](http://192.168.101.86:9000/meta-hub/ai-lab/devdeck/-/releases) 下载（需登录内网 GitLab 并有项目访问权限）。每个版本的说明里附有各文件的 SHA-256 校验值。

| 平台 | 系统要求 | 安装文件 | 大小 |
| --- | --- | --- | --- |
| Windows 安装包 | Windows 10 / 11 x64，WebView2 运行时 | `DevDeck_<版本>_x64-setup.exe` | 约 4.6 MB |
| Windows 便携版 | 同上 | `DevDeck_<版本>_x64_portable.zip` | 约 3.5 MB |
| macOS | macOS 11 及以上 | `DevDeck_<版本>_universal.dmg` 或 `.app.zip` | 约 7.7 MB |

另外需要本机已在使用 Claude Code，并产生过日志。不需要安装 Node.js 或 ccusage。

**Windows**

1. 安装包按当前用户安装，不需要管理员权限；便携版解压后直接运行 `DevDeck.exe`。
2. WebView2 运行时：Windows 11 自带，Windows 10 一般已随系统更新安装。缺少时安装包会自动下载安装，这一步需要联网。
3. 程序未做代码签名。首次运行若出现 SmartScreen「已保护你的电脑」，点击「更多信息 → 仍要运行」。

**macOS**

1. 打开 `.dmg`，将 DevDeck 拖入「应用程序」。
2. 应用未签名。首次打开若提示「无法验证开发者」，在访达中右键 DevDeck → 打开；或在终端执行 `xattr -cr /Applications/DevDeck.app`。

## 使用说明

启动后 DevDeck 会自动找到 Claude Code 日志并在后台完成首次扫描，一般无需任何配置。

1. **首次启动**：按顺序查找日志目录 `CLAUDE_CONFIG_DIR` → `~/.claude` → `~/.config/claude`。首次扫描时页面显示进度，参考：约 1.3 GB 日志全量扫描约 8 秒，之后增量刷新不到 1 秒。
2. **找不到日志时**：在「设置 → 数据源」手动添加目录（需包含 `projects/` 子目录）；也可以添加多个目录一起统计。
3. **查看用量**：打开「每日用量」，选择时间范围、项目和模型；需要留存时点「导出 CSV」。
4. **回看会话**：打开「会话浏览」，用关键字或项目找到会话；要继续该会话，复制 resume 命令后在项目目录中执行。
5. **生成 Insights 报告**：打开「Insights」，点「生成新报告」并确认，完成后自动翻译并显示中文版。

**常用设置**

| 设置项 | 说明 |
| --- | --- |
| 数据源 | 自动检测的日志目录，可手动添加或移除 |
| 时区 | 跟随系统或指定时区，决定用量归入哪一天 |
| 自动刷新 | 1 / 5 / 15 / 30 分钟或关闭 |
| 价格表 | 内置官方价格，可按模型自定义或恢复内置 |
| 套餐额度 | 开启或关闭额度显示 |
| Insights | 开启或关闭模块、翻译为中文、指定 claude 程序路径 |
| 外观与启动 | 主题（跟随系统 / 浅色 / 深色）、开机自启、关闭窗口时最小化或退出 |

## 常见问题与已知限制

**费用和账单对不上？**
费用是按官方价格表计算的估算值，不是账单。使用订阅套餐时，它表示同等用量按 API 计价约合多少。价格变动时可在「设置 → 价格表」中修改。

**为什么有些模型显示「价格未知」？**
内置价格表中没有该模型。可以在价格表中新增该模型并填入价格，其 token 用量不受影响。

**旧会话不见了，用量还在吗？**
Claude Code 会定期清理旧日志。日志被清理后，对应会话无法再打开，但 DevDeck 已记录的历史用量会保留。

**套餐额度显示不出来？**
额度通过本机的 `claude` 命令读取，需要已安装并登录 Claude Code。自动检测不到时，在「设置」中指定 claude 程序路径。

**已知限制**

- 安装包未做代码签名，首次运行会有系统安全提示。
- 既没有 WebView2、又无法联网的 Windows 机器无法安装。
- 便携版的配置和数据仍存在系统应用数据目录，与安装版共用，不跟随程序所在目录。
- 会话详情中的链接不可点击；超长的工具输出会截断显示，图片只显示数量。
- macOS 版已通过编译和自动化测试，但尚未在 Mac 上完整实测。
- 「个人任务」方向的功能仍在规划中。
